[![npm](https://img.shields.io/npm/v/cozyclay)](https://www.npmjs.com/package/cozyclay) [![downloads](https://img.shields.io/npm/dm/cozyclay)](https://www.npmjs.com/package/cozyclay) [![stars](https://img.shields.io/github/stars/HaD0Yun/CozyClay?style=flat)](https://github.com/HaD0Yun/CozyClay/stargazers)

Under the hood: a three.js studio, a deterministic motion compiler that bakes every frame and QA-checks collisions, foot slide and reach, and an MCP server and CLI so agents can drive the scene.

`npx cozyclay` · [cozyclay.org](https://cozyclay.org) · [Discord](https://discord.gg/Hp9V5wwgjF)
