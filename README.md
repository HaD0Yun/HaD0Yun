Open source previs in a browser tab. Block the set, move the cast, cut the camera, hand the shot to an AI video model. Left: the greybox, then the AI video made from it.

Under the hood: a three.js studio, a deterministic motion compiler that bakes every frame and QA-checks collisions, foot slide and reach, and an MCP server and CLI so agents can drive the scene.

`npx cozyclay` · [cozyclay.org](https://cozyclay.org) · [Discord](https://discord.gg/Hp9V5wwgjF)

**Open source**

- [oh-my-codex](https://github.com/Yeachan-Heo/oh-my-codex): maintainer. Hooks, agent teams, HUDs for Codex.
- [GoPeak](https://github.com/HaD0Yun/Doyunha-Gopeak): MCP server for Godot Engine. GDScript LSP, DAP debugger.
- [codex-app-in-linux](https://github.com/HaD0Yun/codex-app-in-linux): Codex desktop app running on Linux.
